Number guessing game

The program picks a number from 1 to 100. The player keeps guessing, and the program says “higher” or “lower” until they win. Then count how many guesses it took. Stretch goal: limit the player to 7 guesses.

A simple path for first year

Your lecturers set the syllabus. This is what to practise on the side.

  1. Learn one language well. Python is friendly to start with. Write a little code every day.
  2. Understand how computers work. Binary, memory, and what happens when code runs.
  3. Get comfortable with logic and maths. It helps with problem solving later.
  4. Learn Git and GitHub. Put every small project online.
  5. Build tiny projects. A calculator, a quiz, a to-do list. Finish them.
